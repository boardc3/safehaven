# Safe Haven Payments — homepage redesign

Prototype redesign of [safehavenpayments.com](https://safehavenpayments.com), built as a single self-contained `index.html` (no build step, no external images; fonts from Google Fonts).

## Run it

Open `index.html` in a browser, or serve it locally:

```
python3 -m http.server 8000
```

then visit http://localhost:8000.

## What's in it

- Hero with an animated statement that tallies and flags hidden fees
- Live fee check (effective rate, gauge, verdict, savings illustration)
- Audience router, how-it-works steps, solutions, story, who-we-serve tabs
- Partner residual calculator with a live growth chart
- FAQ, upgraded lead form with statement upload, sticky mobile action bar

## Before launch

Real logo, attributable testimonials, trust stats, team/merchant photos, and wiring the form to the site's CRM. See `UX-AUDIT.md` for the full audit and checklist.
